# Docs

### Background

Claude and I started writing docs and didn't like anything we produced, and it was very slow going, but I decided to write the docs myself because I had delegated it to Claude for an earlier project and found the docs were so verbose and technical that I felt they were ineffective.  

So we tried a different approach with BonBon. We assumed that users had access to an AI app like Claude or ChatGPT. 

I asked Claude to write a handoff document for another instance of itself re how to help a new user find the features in BonBon that they're looking for.

The doc Claude wrote is so good that humans probably should at least skim it after trying BonBon for a bit on their own. It's really well written imho, and concise, even though when I gave it its instructions I didn't require it to be. This is how Claude talks to one of its own.

Caveat: If we add more files to this folder, unless otherwise stated, will be written by machine.
