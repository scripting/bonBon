# Hello world

A few short steps to create a Markdown file for viewing in BonBon.

1. Create a new Gist on GitHub. Name it hello.md. It must end in .md in order for this to work.

2. Enter some text. Use Markdown code if you like. 

3. In the bottom right [corner](https://imgs.scripting.com/2026/11/16/gistEditorScreenshot.png) of the window, choose Create public gist. Click the button. A new page displays showing a rendering of your markdown, still within GitHub. 

4. In the upper right corner of the window, [click Raw](https://imgs.scripting.com/2026/11/16/pointingAtRaw.png). That takes us to the plain Markdown source code at a long URL, visible in the browser address bar. Copy the [URL](https://gist.githubusercontent.com/scripting/1ae7ab5a8da6accbc4202274cc4301ae/raw/18d88689d1cb43e886f5f24a2db3016aacdf997b/hello.md) to the clipboard.

5. Bring BonBon to the front, paste the URL into its address bar and press return. 

6. If all went well you'll see something [like this](https://imgs.scripting.com/2026/11/16/victory.png). 

You can put the Markdown file anywhere as long as you have a public web address for it. From there you can build structures of Markdown files, to form a web site. 

You may want to edit the URL that GitHub gives you when you click on the Raw link, so that it continues to reflect any edits you make to the document. To do so, take the long string of letters and numbers out of the raw URL. It always gives the current version. Applying this method to the URL returned in step 4, it would become [this](https://gist.githubusercontent.com/scripting/hello.md) much shorter url.
