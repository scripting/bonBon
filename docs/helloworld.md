# Hello world

A few short steps to create a Markdown file for viewing in BonBon.

* Create a new Gist on Github. Name it hello.md.

* Enter some text. Use Markdown code if you like. 

* In the bottom right [corner](https://imgs.scripting.com/2026/11/16/gistEditorScreenshot.png) of the window, choose Create public gist.

* Click the button. A new page displays showing a rendering of your markdown, still within GitHub. 

* In the upper right corner of the window, [click Raw](https://imgs.scripting.com/2026/11/16/pointingAtRaw.png). That takes us to the plain Markdown source code at a long URL, visible in the browser address bar. Copy the [URL](https://gist.githubusercontent.com/scripting/1ae7ab5a8da6accbc4202274cc4301ae/raw/18d88689d1cb43e886f5f24a2db3016aacdf997b/hello.md) to the clipboard.

* Bring BonBon to the front, paste the URL into its address bar and press return. 

* If all went well you'll see something [like this](https://imgs.scripting.com/2026/11/16/victory.png). 

You can put the Markdown file anywhere as long as you have a public web address for it. From there you can build structures of Markdown files, to form a web site. Not being sarcastic, just remembering that these ideas had meaning a long time ago.
