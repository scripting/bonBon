# Hello world

A few short steps to creating a Markdown file for viewing in BonBon.

* Create a new Gist on Github. Name it hello.md.

* Enter some text. Use Markdown code if you like. 

* In the bottom right corner of the window, choose Create public gist.  

* Click the button. A new page displays showing a rendering of your markdown, still within GitHub. 

* In the upper right corner of the window, click Raw. That takes us to the plain Markdown source code at a long URL, visible in the browser address bar. Copy the [URL](https://gist.githubusercontent.com/scripting/1ae7ab5a8da6accbc4202274cc4301ae/raw/18d88689d1cb43e886f5f24a2db3016aacdf997b/hello.md) to the clipboard.

* Bring BonBon to the front, paste the URL into its address bar and press return. 

You can put the Markdown file anywhere as long as you have a public web address for it.
