# Source code release

First release contains the code for the Electron apps on Nov 20, 2026. 

To build and run either a Mac or Linux app, this is what you do.

* Requires a Node install, version 18.20.8 is what we build it with.

* Download the code folder, open it in a terminal window.

* npm install

* npm start
