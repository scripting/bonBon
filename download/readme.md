# Download BonBon

### Macintosh download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/mac.zip).

It contains one file, BonBon.

When you run the app, the Mac OS will require that you approve the download before you can run it.

Note: The Mac build runs only on Apple silicon.

### Linux download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/linux.zip).

It contains one folder, BonBon, which contains the program plus the files it needs beside it.

Launch it as you would any other desktop app.

Note: The Linux build runs only on Intel-type chips.

### Windows download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/windows.zip).

It contains one folder, BonBon, which contains the program plus the files it needs beside it.

Open the folder and double-click on BonBon.exe. There's no installer. 

The first time, Windows shows a blue box, "Windows protected your PC". Click More info, then Run anyway.

It's for 64-bit Windows 10 or 11.

It has not been tested, if you try it, [let us know](https://github.com/scripting/bonBon/issues/21) how it works by posting a comment in Issues. 

### Raspberry download

Download and expand [this zip file](https://github.com/scripting/bonBon/releases/latest/download/raspberry.zip).

Run the program named BonBon in the folder.

It needs a 64-bit Raspberry Pi system. A 32-bit one can't run it. 

It has not been tested, if you try it, [let us know](https://github.com/scripting/bonBon/issues/21) how it works by posting a comment in Issues.
