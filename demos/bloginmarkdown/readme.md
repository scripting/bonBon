# Scripting News as a markdown blog

We started with the OPML archive in the Scripting-News GitHub repo, and then keep it current with the RSS 2.0 feed. 

We also use front matter, and are compatible with the major static site generators, and macros. 

Click [here](https://github.com/scripting/bonBon/raw/main/demos/bloginmarkdown/scripting.zip) to download the archive.
