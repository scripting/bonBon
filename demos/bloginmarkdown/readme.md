# Scripting News as a Markdown site

We started with the [OPML archive](https://github.com/scripting/Scripting-News/tree/master/blog/opml) in the Scripting-News GitHub repo, and then keep it current with the RSS 2.0 feed. 

We also use [front matter](https://www.markdowntools.com/blog/markdown-frontmatter-metadata-complete-guide), and are compatible with the major static site generators, and macros. 

Click [here](https://github.com/scripting/bonBon/raw/main/demos/bloginmarkdown/scripting.zip) to download the archive. 

You can view Dave's blog in BonBon [here](https://demo.bonbonweb.org/?url=https%3A%2F%2Fdave.writersweb.org%2Fscripting%2Findex.md).
