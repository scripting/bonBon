# Brent's blog as a Markdown site

[Brent Simmons](https://inessential.com/what-i-do.html)' long-running blog is [inessential.com](https://inessential.com/). The Markdown site we built from his source has all the same content, but adds special features for blogs you read in the BonBon browser. Of course it can be viewed in any Markdown-aware browser. 

We started with the Markdown [archive](https://github.com/brentsimmons/inessential.com) Brent maintains on GitHub, and from that ran the same Node app Claude wrote for Scripting News. We are following his RSS 2.0 feed for new posts and updates. 

You can view Brent's blog viewed in BonBon [here](https://demo.bonbonweb.org/?url=https%3A%2F%2Fbrent.writersweb.org%2F).

Click [here](https://github.com/scripting/bonBon/raw/main/demos/brentbloginmarkdown/inessential.zip) to download the archive.
