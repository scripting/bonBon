# Brent's blog as a Markdown site

Brent Simmons' long-running blog is [inessential.com](https://inessential.com/). The Markdown site has all the same content, but adds special features for blogs hosted by BonBon. Of course it can be viewed in any Markdown-aware browser. 

We started with the Markdown [archive](https://github.com/brentsimmons/inessential.com) Brent maintains on GitHub, and from that ran the same Node app Claude wrote for Scripting News. We are following his RSS 2.0 feed for updates. 

Click [here](https://github.com/scripting/bonBon/raw/main/demos/brentbloginmarkdown/inessential.zip) to download the archive.
